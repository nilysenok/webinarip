# webinarip

Скачивает запись вебинара MTS Link одним файлом: **85-минутный вебинар в MP3 — за {{HEADLINE}} с** с пустого кэша. Звук всех участников сводится в один трек; видео участников, их отдельные дорожки и монтажный проект — по флагу. Один бинарник ~4 МБ, без зависимостей.

[English](README.en.md)

> Только для записей, к которым у вас есть права: свои вебинары или с разрешения организатора.
> Проект независимый и не связан с МТС и MTS Link.

## Установка

- **Готовый бинарник** — [Releases](https://github.com/nilysenok/webinarip/releases): macOS (Apple Silicon, Intel), Linux (x86_64, arm64), Windows (x86_64).
- **macOS и Linux** одной строкой:
  ```sh
  curl --proto '=https' --tlsv1.2 -LsSf https://github.com/nilysenok/webinarip/releases/latest/download/webinarip-installer.sh | sh
  ```
- **Windows** (PowerShell):
  ```powershell
  powershell -ExecutionPolicy Bypass -c "irm https://github.com/nilysenok/webinarip/releases/latest/download/webinarip-installer.ps1 | iex"
  ```
- **Из исходников** (Rust 1.85+): `cargo install --git https://github.com/nilysenok/webinarip webinarip`

## Примеры

```sh
# Вся запись в MP3 (моно 64 кбит/с — для речи; --quality high — стерео 128)
webinarip https://my.mts-link.ru/j/…/record-new/123456789

# С 10-й минуты до 1:20:00, только ведущий и дорожка №3, WAV 16 кГц для расшифровки
webinarip <ссылка> --from 10:00 --to 1:20:00 --tracks host,3 --quality low --wav

# MP3 + видео каждого участника (WebM) + их исходные дорожки + проект для монтажа
webinarip <ссылка> --both --multicam
```

`webinarip <ссылка> --list` покажет дорожки с номерами, `webinarip serve` откроет интерфейс в браузере: вставили ссылку — загрузка началась, плеер играет, пока файл докачивается, история сохраняется.

Время в `--from/--to`: `75` — секунды, `10:00` — минуты и секунды (как в ffmpeg), `1:20:00` или `1h20m` — с часами. Каждый запуск кладёт результат в свою папку `ГГГГ-ММ-ДД_ЧЧММ <название>/`; скачанные сегменты кэшируются, поэтому другой формат или отрезок той же записи — без повторной загрузки.

## Закрытая запись: session-id за 3 шага

1. Откройте запись в браузере, войдя в аккаунт.
2. Инструменты разработчика (F12 или ⌥⌘I) → Application → Cookies → `my.mts-link.ru`.
3. Скопируйте значение `sessionId` и передайте его: `--session-id <значение>` или переменная `WEBINARIP_SESSION_ID`. На диск он не записывается.

## Как это работает

1. Запись — это набор параллельных медиасессий: у каждого участника своя дорожка со своим временем начала.
2. Из HLS каждой дорожки качается только аудио (~100 кбит/с), видео — только если его попросили.
3. Дорожки звучат одновременно, поэтому их нельзя склеить подряд: они сводятся на общей шкале по времени начала (сумма без нормализации и лимитер).
4. Сведение и кодирование идут прямо во время загрузки; сегмент, которого ждёт микшер, запрашивается вне очереди.
5. Только HTTP/1.1: сервер ограничивает скорость одного соединения, и HTTP/2 со своим единственным соединением в 7,7 раза медленнее — поэтому много соединений, но не больше 256.

## Ограничения

- **Видео — как его записал сервис.** В проверенной записи камеры участников — 320×180, 25 кадров/с: webinarip копирует кадры без перекодирования и качество не улучшает.
- **WebM (VP9) не открывается в QuickTime.** Для QuickTime и монтажных программ есть `--mp4`: перекодирование системным ffmpeg, это минуты, а не секунды.
- **Дорожки участников (.m4a) режутся по границам сегментов, ~13 с:** это исходные байты без перекодирования. Смещения в монтажном проекте это учитывают.
- **Импорт FCPXML в Final Cut Pro и DaVinci Resolve не проверялся.** Файл собирается по спецификации и проходит проверку XML; EDL (CMX3600) по формату однодорожечный.
- **AAC** (`--aac`) на macOS кодируется системным AudioToolbox, на Linux и Windows — системным ffmpeg.

## Этика

- **Жёсткий потолок — 256 одновременных соединений.** Меньше можно (`--connections`), больше — нет.
- **HTTP 429 соблюдается:** число соединений делится пополам, все запросы ждут `Retry-After`.
- **Только свои записи** или записи, на которые у вас есть разрешение. session-id живёт в памяти процесса и нигде не сохраняется.
